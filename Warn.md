# 🏅 Spoofer Discord Badges

Uma ferramenta desenvolvida em JavaScript para personalização e modificação da exibição de badges no Discord. O projeto busca oferecer uma experiência simples, com recursos de personalização, configurações acessíveis e interface traduzida para português do Brasil (PT-BR).

## ✨ Funcionalidades

- 🏅 Personalização da exibição de badges do Discord.
- ⚙️ Configuração do ambiente para utilizar os recursos da ferramenta.
- 🇧🇷 Interface e mensagens em português do Brasil.
- 💻 Desenvolvido em JavaScript.
- 🎨 Experiência de uso simples e intuitiva.

## 🚀 Pré-requisitos

- Discord instalado no Windows.
- Acesso à pasta de configuração do Discord.
- Arquivos do projeto baixados e extraídos.

## 🔧 Como ativar o Developer Tools

Para utilizar os recursos que dependem das ferramentas de desenvolvedor, siga estas etapas:

**1. Abra a pasta AppData**

Pressione `Win + R`, digite:

```text
%appdata%
```

Pressione Enter.

**2. Entre na pasta do Discord**

Abra a pasta:

```text
Discord
```

**3. Localize o arquivo de configuração**

Encontre o arquivo:

```text
settings.json
```

Faça uma cópia de segurança desse arquivo antes de editá-lo.

**4. Adicione a configuração**

Abra `settings.json` em um editor de texto e adicione a seguinte propriedade ao objeto JSON:

```json
"DANGEROUS_ENABLE_DEVTOOLS_ONLY_ENABLE_IF_YOU_KNOW_WHAT_YOURE_DOING": true,
```

Se já houver outras propriedades no arquivo, respeite a sintaxe JSON: coloque uma vírgula entre as propriedades e não adicione uma vírgula indevida no final.

**5. Reinicie o Discord**

Feche completamente o Discord, inclusive na bandeja do sistema, e abra-o novamente.

> ⚠️ **Atenção:** essa configuração habilita ferramentas de desenvolvedor e pode permitir a execução de código no contexto do cliente. Utilize apenas ferramentas e códigos de fontes confiáveis. Atualizações do Discord podem alterar o funcionamento dessa configuração.
